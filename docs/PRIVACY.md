# ForgeWin privacy

ForgeWin reads the ISO you select, inspects local storage devices, and writes the USB drive you explicitly confirm. WIM preparation may use temporary files on the Mac. USB creation erases the selected physical drive.

The app has no account system, analytics, tracking, advertising or automatic upload of files, operation history or errors. It stores the most recent operation history and last error locally in macOS preferences. These records may include local paths, filenames and drive information.

Microsoft download links open the default browser. The sites you visit and GitHub issue reports are separate from the app's local processing. Only submit information you intend to share publicly, and remove personal details from diagnostics first.

The application includes an Apple privacy manifest describing its use of local preferences, file metadata and available disk space.
